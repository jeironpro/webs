# Tests DAW

Plataforma de tests del ciclo formativo de Desarrollo de Aplicaciones Web (DAW): cuestionarios de preguntas tipo test organizados por módulos.

## Características

- Tests agrupados por módulos del ciclo DAW: bases de datos, diseño de interfaces, lenguajes de marcas, programación y sistemas informáticos.
- Preguntas tipo test con selección de respuesta.
- Barra de progreso y retroalimentación inmediata.
- Pantalla de resultados con gráfico, temas a repasar y opción de reiniciar.
- Progreso guardado en el almacenamiento local del navegador.
- Navegación con teclado y menú adaptado a móvil.

## Tecnologías

- HTML5, CSS3 y JavaScript (ES6+).
- Preguntas almacenadas en archivos JSON por módulo.

## Uso

1. Clona el repositorio.
2. Abre `index.html` en el navegador o sirve la carpeta con un servidor estático local.
3. Selecciona una categoría y un tema, pulsa Iniciar y responde las preguntas del test.
