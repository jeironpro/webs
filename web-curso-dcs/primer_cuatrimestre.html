Teoria: Diseno UI/UX

El diseno es un proceso de prefiguracion mental, de planificacion creativa en el que se persigue la solucion para un problema en concreto. Abarca aspectos como la forma, la funcionalidad, la operatividad y vida util del producto.

Ramas del Diseno
  • Diseno Grafico: creacion de piezas utilizando herramientas graficas digitales o analogicas
  • Diseno Editorial: creacion de revistas, periodicos, libros
  • Diseno Tipografico: creacion de tipografias
  • Diseno Publicitario: creacion de piezas para medios publicitarios
  • Diseno de Identidad Corporativa: creacion de marca e identidad de una empresa
  • Diseno Multimedia: implementacion de contenidos en multiples soportes
  • Diseno Web: creacion de paginas web
  • Diseno UI (Interfaz de Usuario): es la vista que permite al usuario interactuar con un sistema
  • Diseno UX (Experiencia de Usuario): como se siente una persona mientras utiliza una interfaz
Procesos del Diseno
  1. Planificacion: se crea el plan de accion para el trabajo a desarrollar
  2. Investigacion y analisis: se analiza el mercado y los usuarios
  3. Ideacion: se proponen ideas y conceptos
  4. Verificacion del diseno: comprobacion de que el diseno cumple los objetivos
  5. Prototipado y ejecucion: aplicacion final del diseno
  6. Finalizacion: entrega del producto final
Usabilidad

Medida empirica y relativa de la utilidad, facilidad de aprendizaje, rendimiento y apreciacion de los usuarios. La usabilidad esta compuesta por caracteristicas como la eficiencia, eficacia, satisfaccion, accesibilidad, comunicacion y curva de aprendizaje.

Elementos del Diseno

Lineas, Color, Forma, Tamano, Textura, Espacios

Leyes de UX
  • Ley de Fitts: el tiempo para alcanzar un objetivo depende del tamano y distancia
  • Ley de Hick: el tiempo de decision aumenta con el numero de opciones
  • Ley de Jakob: los usuarios prefieren sistemas familiares
  • Ley de la Proximidad: los elementos cercanos se perciben como relacionados
  • Ley de Miller: la memoria a corto plazo solo almacena 7 +/- 2 elementos
  • Ley de Pareto: el 80% de los efectos proviene del 20% de las causas
  • Efecto Estetico-Usabilidad: los disenos atractivos se perciben como mas usables
  • Efecto de Posicion Serial: es mas probable recordar el primer y ultimo elemento
  • Efecto Von Restorff: el elemento diferente es mas facil de recordar
  • Ley de Tesler: cada aplicacion tiene una complejidad inherente que no se puede reducir
  • Efecto Zeigarnik: las tareas incompletas se recuerdan mejor que las completadas

Teoria: Fundamentos de Python

Python es un lenguaje de programacion de proposito general, interpretado, orientado a objetos, dinamico y multiplataforma. Creado por Guido van Rossum a finales de los ochenta. Se caracteriza por su sintaxis clara y legible. Es un lenguaje de alto nivel que permite desarrollar todo tipo de aplicaciones: web, escritorio, cientificas, inteligencia artificial, etc.

Para programar se necesita tener conocimientos del lenguaje y logica de programacion. La logica de programacion es un conjunto de tecnicas para resolver problemas de manera ordenada siguiendo pasos logicos y estructurados.

Palabras Reservadas

False, None, True, and, as, assert, async, await, break, class, continue, def, del, elif, else, except, finally, for, from, global, if, import, in, is, lambda, nonlocal, not, or, pass, raise, return, try, while, with, yield

Implementaciones de Python
  • CPython: implementacion predeterminada escrita en C
  • Jython: se ejecuta en la plataforma Java
  • IronPython: usa librerias .NET Framework
  • PyPy: escrita en Python, mas rapida
Variables

Se utilizan para almacenar datos. Las variables no necesitan declaracion de tipo explicita, Python infiere el tipo automaticamente. Los nombres de variables son case-sensitive y deben comenzar con letra o guion bajo.

Tipos de Datos
  • Numericos: int (enteros), float (decimales), complex (complejos)
  • Booleanos: bool (True / False)
  • Cadenas: str (cadenas de caracteres)
  • Secuencias: list, tuple, range
  • Conjuntos: set, frozenset
  • Diccionarios: dict (pares clave-valor)
Operadores

Aritmeticos: +, -, *, /, %, //, **

Relacionales: ==, !=, <, >, <=, >=

Logicos: and, or, not

Bitwise: <<, >>, &, |, ^, ~

Asignacion: =, +=, -=, *=, /=

# Encolar elementos
cola.append(1)

cola.append(3)

Manejo Linux

Concepto de Linux Linux es un sistema operativo compuesto por software libre y de código abierto parecido a Unix, creado por el filandes Linus Torvalds. Su software libre implica que cualquier persona puede ver el código fuente y modificarlo para crear distribuciones que derivan de Linux y usarla en computadoras, servidores, mainframes y dispositivos móviles. Linux como tal es solo un kernel y el sistema está compuesto por una gran cantidad de componentes de terceros, que van desde compiladores hasta entorno de escritorio. Concepto de software libre y gestor de paquete Concepto de software libre Software libre es un software cuyo código fuente puede ser utilizado por cualquier persona y para sus propios fines. El software libre puede ser estudiado, modificado y redistribuido con cambios o mejoras. El software libre es creado por el activista y experto informático Richard Stallman bajo su fundación la free software fundation.

Concepto de gestor de paquete El gestor de paquetes es una interfaz formada por una colección de herramientas que asiste al usuario automatizando los procesos de instalación, actualización, configuración y eliminación de paquete de software.

Tipos de formatos de los paquetes tgz (archivos tar gzip): que básicamente son archivos con el código fuente. Pueden tener todo lo que el responsable del paquete considera útil. Además del formato de archivo propio, necesario para extraer los archivos, no hay nada estándar sobre el contenido de un archivo tgz. Tienen que ser compilados para poder ejecutar el software. Rpm (rpm package manager): que son archivos pre-compilados. Creados por Red Hat Linux y estandarizado por el LSB, se utiliza en la actualidad por muchas distribuciones de Linux como sistema de empaquetado de su software, incluyendo openSUSE. deb: (Debian) Son archivos precompilados utilizados por Debian u otros de los sistemas derivados de este (Ubuntu, Mint, etc.) Núcleo o kernel Núcleo o kernel es el corazón de un sistema operativo que se encargar de medir entre los procesos del usuario y el hardware disponible, es decir le concede el acceso al hardware para el software que lo solicite de manera segura. El kernel es también responsable de los controladores más importantes que pueden acceder directamente al hardware y gestionar sus recursos de la manera más eficiente. El Shell El Shell es un intérprete de comandos de un sistema operativo que provee una interfaz de usuario para acceder a los servicios del sistema, mediante las instrucciones que aporta el intérprete, el usuario puede comunicarse con el núcleo. Shell es cualquier interprete que los usuarios usen para escribir comandos. Los comandos que aportan los intérpretes, pueden usarse a modo de guion si se escriben en ficheros ejecutables denominados Shell-scripts, de este modo, cuando el usuario necesita hacer uso de varios comandos o combinación de comandos con herramientas, escribe en un fichero de texto, marcado como ejecutable, las operaciones que posteriormente, línea por línea, el intérprete traducirá al núcleo para que las realice. Sistema de archivos El sistema de archivos es una estructura de directorios completa que contiene un directorio raíz y un subdirectorio que maneja los archivos y controla como se almacenan y recuperan los datos. Sin un sistema de archivos, los datos colocados en un medio de almacenamiento serían un gran cuerpo de datos sin manera de saber dónde termina un dato y comienza el siguiente. El sistema de archivos le permite al usuario identificar la ubicación de los archivos y poder acceder a ellos de manera segura, también se encarga de administrar y facilitar el uso de las memorias periféricas, la asignación de espacios a los archivos, la administración del espacio libre y del acceso a los datos resguardados. Los sistemas de archivos proveen métodos para crear, mover, renombrar y eliminar tanto archivos como directorios. Diferencia de Linux con otros sistemas operativos La principal diferencia es que Linux es libre y gratis, mientras que los demás son privativos y de pago. Linux necesita un menor mantenimiento ante los demás sistemas operativos. Linux es más seguro ya que es libre y cualquiera puede tener acceso a su código fuente y modificarlo como quiera, en cambio Windows es más atacado por los hackers. Linux es multitarea real, multiusuario y posee un esquema de seguridad donde los usuarios son los que dan permiso de lectura, escritura y ejecución a los archivos y directorios. Ante Mac, Linux es más simple en cuanto a control para los usuarios. Estructura de directorios La estructura de directorios suele ser la de un árbol, dentro de ese árbol los directorios se ordenan de forma jerárquica. Cada directorio puede tener uno o más subdirectorios. En cada subdirectorio podemos encontrar ficheros con idéntico nombre, también en algunos sistemas está permitido que un mismo fichero este en varios directorios. /dev, Contiene archivos especiales para dispositivos de E/S. /etc, Contiene archivos para la inicialización del sistema y la gestión del sistema. /home, Contiene directorios de inicio de sesión para los usuarios del sistema. /tmp, Contiene archivos que son temporales y que se suprimen automáticamente después de un número especificado de días. /usr, Contiene lpp, include y otros directorios del sistema. /usr/bin, Contiene programas ejecutables de usuario. Interprete de comandos Un intérprete de comandos es un programa informático que tiene la capacidad de traducir las órdenes que introducen los usuarios, mediante un conjunto de instrucciones facilitadas por el mismo directamente al núcleo y al conjunto de herramientas que forman el sistema operativo. El intérprete de comando permite la comunicación entre el sistema y el usuario. Existen muchos intérpretes de comandos: Unix: Korn Shell (ksh), C Shell (csh), Bourne Shell (sh), Bourne Again Shell (bash), Tcsh, Z Shell (zsh); Windows: command.com, cmd.exe, MSH Windows PowerShell.

Sistema Control Versiones Git Github

Concepto de sistema de control de versiones Los sistemas de control de versiones son software que permite hacer seguimientos a cambios realizados a un código de un proyecto que mientras se edita el código, el sistema de control de versiones toma instantánea de los archivos. Estos softwares ayudan a grupos de desarrolladores a gestionar los cambios de un código fuente y que todos puedan darle seguimiento al trabajo de cada uno y así poder aportar a su propio trabajo como al de los demás. Las versiones de los proyectos están sujetas a una revisión y edición viendo así el estado en el que se encuentran. Los sistemas de control de versiones cuentan con repositorio local y remoto. En el local los cambios no se comparten con nadie y el remoto donde el código es encontrado en un servidor.

Concepto de Git Git es un sistema de control de versiones distribuido creado por Linus Torvalds, que se ha convertido en el control de versiones más popular y usado. Git es distribuido lo que significa que un clon local del proyecto es un repositorio de control de versiones completo. Git fue creado para ser eficiente, confiable y compatible, su propósito es llevar registros de los cambios en archivos de un proyecto. Git almacena y maneja la información de forma muy diferente a otros sistemas, a pesar de que su interfaz de usuario es bastante similar. Git cuenta con tres secciones principales de un proyecto: el directorio de Git (Git directory), el directorio de trabajo (working directory) y el área de preparación (staging area).

Concepto de GitHub GitHub es una plataforma de desarrollo colaborativo para alojar proyectos utilizando el sistema de control de versiones Git. GitHub permite que los desarrolladores alojen proyectos creando repositorio de forma gratuita, pero para subir gratis los proyectos deberán ser de código abierto. GitHub ofrece una serie de herramientas propias como la opción de poder crear una wiki para cada proyecto, también tiene un sistema de seguimiento de problemas, para que otras personas puedan hacer mejoras, sugerencias y optimizaciones en los proyectos, también ofrece una herramienta de revisión de código para así dejar anotaciones para que el proyecto pueda ser revisado por ti o los demás y por último se pueden crear discusiones alrededor de las anotaciones para mejorar y optimizar el código.

Comandos básicos de Git git add -> agregar contenido de archivo al índice. git am -> aplicar una serie de parches desde un buzón. git archive -> crear un archivo de archivos a partir de un árbol con nombre. git bisect -> use la búsqueda binaria para encontrar la confirmación que introdujo un error. git branch -> enumerar, crear o eliminar sucursales. git bundle -> mover objetos y referencias por archivo. git checkout -> cambie de rama o restaure los archivos del árbol de trabajo. git cherry pick -> aplicar los cambios introducidos por algunos commits existentes. git citool -> alternativa gráfica a git commit. git clean -> eliminar archivos sin seguimiento del árbol de trabajo git clon -> clonar un repositorio en un nuevo directorio. git commit -> registrar cambios en el repositorio. git describe -> dar a un objeto un nombre legible por humanos basado en una referencia disponible. git diff -> Mostrar cambios entre confirmaciones, confirmación y árbol de trabajo, etc. git fetch -> descargar objetos y referencias de otro repositorio. git format patch -> preparar parches para enviar por correo electrónico. git gc -> limpie archivos innecesarios y optimice el repositorio local. git grep -> imprimir líneas que coincidan con un patrón. git gui -> una interfaz gráfica portátil para Git. git init -> cree un repositorio Git vacío o reinicie uno existente. git log -> mostrar registros de confirmación. git maintenance -> ejecute tareas para optimizar los datos del repositorio de Git. git merge -> unir dos o más historias de desarrollo juntas. git mv -> mover o cambiar el nombre de un archivo, un directorio o un enlace simbólico. git notes -> agregar o inspeccionar notas de objetos. git pull -> obtenga e integre con otro repositorio o una sucursal local. git push -> actualizar referencias remotas junto con objetos asociados. git range diff -> compara dos rangos de confirmación (por ejemplo, dos versiones de una rama). git rebase -> vuelva a aplicar compromisos encima de otro consejo base. git reset -> restablecer HEAD actual al estado especificado. git restore -> restaurar archivos de árbol de trabajo. git rever -> revertir algunas confirmaciones existentes. git rm -> eliminar archivos del árbol de trabajo y del índice. git shortlog -> resumir la salida del registro de git. git show -> mostrar varios tipos de objetos. git sparse checkout -> reduzca su árbol de trabajo a un subconjunto de archivos rastreados. git stash -> guarde los cambios en un directorio de trabajo sucio. git status -> mostrar el estado del árbol de trabajo. git submodule -> inicializar, actualizar o inspeccionar submódulos. git switch -> cambiar de sucursal. git tag -> cree, enumere, elimine o verifique un objeto de etiqueta firmado con GPG. git worktree -> administrar múltiples árboles de trabajo. gitk -> el navegador del repositorio Git. escalar -> una herramienta para gestionar grandes repositorios Git .
