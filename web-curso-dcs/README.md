# Diseño y Creación de Software — Portafolio del Curso

Sitio web estático que recopila todo el contenido del curso **Diseño y Creación de Software** (INFOTEP, 2022, 900 horas, facilitador José Luis Alonzo).

## Contenido

- **I Cuatrimestre** — Fundamentos: Linux, Python, Git, Diseño UI/UX
- **II Cuatrimestre** — Desarrollo Web: HTML, CSS, JavaScript, Node.js, APIs
- **III Cuatrimestre** — Especialización: SQL, Python Avanzado, POO, Django, MongoDB, Java
- Proyecto integrador **Alpha Inventory** (Flask + Django)

## Arquitectura

| Archivo | Descripción |
|---|---|
| `index.html` | Hub de navegación |
| `primer_cuatrimestre.html` | Contenido del I cuatrimestre |
| `segundo_cuatrimestre.html` | Contenido del II cuatrimestre |
| `tercer_cuatrimestre.html` | Contenido del III cuatrimestre |
| `css/styles.css` | Estilos personalizados |
| `js/app.js` | Interactividad (acordeones, scroll, menú móvil) |
| `assets/` | PDFs e imágenes referenciados |

Built with HTML + Tailwind CSS (CDN) + JavaScript vanilla. Sin frameworks ni build steps.

## Uso

Abrir `index.html` en cualquier navegador moderno. No requiere servidor.
