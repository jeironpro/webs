Qué se comprobó de verdad

  • Navegador: Chromium real sobre el servidor local; 1–3 páginas por web según el tamaño, con escritorio 1440×900 y móvil 390×844. Se registraron errores de consola, excepciones JS, respuestas HTTP ≥400, peticiones locales fallidas, imágenes rotas y desbordamiento horizontal.

  • CSS: media queries mobile-first, custom properties, px, hex fuera de tokens, !important, selectores genéricos y comentarios.
  • JS: innerHTML/outerHTML/insertAdjacentHTML, var, igualdad no estricta, .then, require, console y comentarios.
  • Favicon y README: enlace real al favicon, SVG localizable y enlaces locales del README.

Criterios y límites

  • Sí: sin hallazgos en esa dimensión. Parcial: deuda acotada o fallo externo. No: incumplimiento claro o error de ejecución.
  • Navegador: un error JS, un 404 local o una carga fallida impiden el Sí; las imágenes externas caídas se marcan como parciales.
  • Idioma: se miran identificadores, clases, funciones y variables, no los textos visibles. «Parcial» significa pocos términos españoles aislados.
  • Las webs de cursos y documentación incluyen contenido y ejemplos extensos; se excluyeron plantillas, builds y código generado. Las métricas estáticas cubren todo el código versionado, mientras que el navegador usa una muestra de hasta tres páginas por web.
  • Los fallos 503 de servicios externos (por ejemplo, tarjetas de GitHub) se registran como parciales, no como errores del código local.
