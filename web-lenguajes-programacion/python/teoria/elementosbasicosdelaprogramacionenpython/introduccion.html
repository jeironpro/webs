''' Introducción a Python
Python es un lenguaje de programación de alto nivel y proposito general, diseñado para ser fácil de leer, escribir y mantener. Es ampliamente utilizado en diversas áreas, como desarrollo web, análisis de datos, inteligencia artificial, automatización de tareas y muchos más.

· Características principales de Python:
1. Sintaxis sencilla y legible:
-Python utiliza indentación (espacios o tabulaciones) para definir bloques de código.
-Esto lo hace más limpio y fácil de leer, incluso para principiantes.

2. Multiparadigma:
-Soporta programación estructurada, orientada a objectos y funcional.

3. Interpretado y multiplataforma:
-Puede ejecutar el mismo código en diferentes sistemas operativos (Linux, Windows, macOS, etc.) sin necesidad de modificarlo.

4. Gran cantidad de bibliotecas:
-Python tiene bibliotecas para casi todo: desde matemáticas hasta desarrollo web y aprendizaje automático.

5. Comunidad grande y activa:
-Hay mucha documentación, foros y recuros en línea disponibles para aprender y resolver problemas.

· Primer programa en Python
El programa clásico de inicio es el "Hola, mundo". Para ejecutarlo, seguir estos pasos:
1. Abre el terminal y crea un archivo llamado hola.py con el editor de texto que prefieras:
    gedit hola.py

2. Escribe el siguiente codigo:
    print("Hola, mundo!")

3. Guarda (Ctrl + s) y cierra el archivo.

4. Ejecuta el archivo en la terminal:
    python3 hola.py

5. La salida por pantalla será:
    Hola, mundo!
'''
