Python — DCS (INFOTEP)

Teoría y ejercicios de Python del programa DCS de INFOTEP, desde los elementos básicos del lenguaje hasta frameworks (Flask y Django). PYTHON Nota El contenido de este lenguaje de programación es una combinación de lo aprendido en un curso técnico (Diseño y Creación de Software) que realicé en el Instituto Nacional de Formación Técnico Profesional en la República Dominicana, junto con teorías y ejercicios proporcionados por ChatGPT. Por último, y lo más importante, el contenido expuesto en este repositorio no refleja el conocimiento que poseo.
