# Java — DAW (ITIC Barcelona)

Teoría y ejercicios de Java del ciclo DAW impartido en el instituto de Tecnologías de la Información y Comunicación de Barcelona. Cada lección incluye la teoría comentada y ejemplos de código ejecutables.
JAVA
**Nota**
El contingut d'aquest llenguatge de programació és una combinació de l'après en un Grau Superior (Desenvolupament d'Aplicacions Web (DAW)) que realitzo en l'institut de Tecnologies de la Informació i Comunicació de Barcelona a Espanya, divideixo amb teories proporcionades per ChatGPT i exercicis del curs. Finalment, i el més important, el contingut exposat en aquest repositori no reflecteix el coneixement que posseeixo.
