Declaració i assignació

Declaració i assignació La declaració La declaració d’una variable és el procés de crear-la i definir quin tipus de dada emmagatzemarà. En Java, cal especificar el tipus de dada abans del nom de la variable.

Alguns exemples de tipus de dades bàsics són

  • int (números enters)

  • double (nombres decimals)

  • boolean (valor lògics: true o false)

  • char (caràcters individuals)

Exemple de declaració

int edad;
double altura;
boolean esEstudiant;
char inicial;

En aquest exemple, estem declarant quatre variables: edat com a enter (int), altura com a decimal (double), esEstudiant com a booleá i inicial com a carácter.

La assignació La assignació és el procés de donar un valor a una variable. En Java, fem servir el signe = per assignar el valor.

Exemple d’assignació

edat = 25;
altura = 1.75;
esEstudiante = true;
inicial = 'A';

Aquí, estem assignat valors a les variables que havíem declarat. Ara edat té el valor 25, altura té 1.75, esEstudiant té true i inicial té el carácter A.

Declaració i assignació en una sola línia També és possible fer la declaració i l’assignació alhora, en una mateixa línia de codi.

Exemple

int edat = 25;
double altura = 1.75;
char inicial = 'A';

Això ens permet estalviar línies de codi i fer el nostre codi més compacte.
