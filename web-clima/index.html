    Privacidad · Clima°

    Tu clima, guardado solo aquí

    Clima° usa almacenamiento local para recordar tu última ciudad y tu unidad de temperatura. No usa cookies ni envía tus datos a ningún servidor. Al aceptar, la página se recargará para aplicar el guardado.

    Privacidad · sin guardado

    El clima funcionará sin memoria

    Puedes consultar el tiempo durante esta visita, pero tu última ciudad y la unidad volverán a los valores iniciales al recargar. No se guardará nada en tu navegador. Puedes activar el guardado desde «Privacidad».

    Privacidad · guardado activo

    El almacenamiento local está activo

    Clima° recuerda tu unidad y tu última ciudad en este navegador. Puedes retirar el permiso y borrar esos datos cuando quieras.

    Privacidad · borrar datos

    ¿Borrar los datos de Clima°?

    Se eliminarán la unidad, la última ciudad y la preferencia de consentimiento de este navegador. La página se recargará y el aviso volverá a aparecer.

    El navegador bloquea el almacenamiento local. No se pudo completar la operación.
