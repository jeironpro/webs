    Referencia / Chuleta del curso

    La chuleta del curso

    Las tres palancas que más se repiten y una idea de bolsillo por cada módulo. Úsala para repasar antes de diseñar o de explicar una decisión.

    Tres palancas, tres costes

    01 más cerca

    Cachear

    Responder antes de volver a preguntar.

    Señal
    Las mismas lecturas se repiten y toleras datos de hace segundos.
    Coste
    Invalidar a tiempo. Una caché sin política es una mentira rápida.

    Primer paso Mide el hit ratio y el coste de un fallo.

    02 más lectura

    Replicar

    Dar réplicas a lo que solo necesita leer.

    Señal
    Las lecturas dominan y la base de datos ya tiene cola.
    Coste
    Lag de replicación. Tu usuario puede leer algo que aún no pasó.

    Primer paso Separa el camino de lectura del de escritura.

    03 más lejos

    Partir

    Cambiar un límite por muchos límites pequeños.

    Señal
    Un tenant, una tabla o una región concentra casi toda la carga.
    Coste
    Operación, transacciones y consultas que cruzan particiones.

    Primer paso Elige la clave de partición antes de tocar el esquema.
