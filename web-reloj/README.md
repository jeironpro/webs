# web-reloj

Reloj web con un reloj analógico animado en 3D, temporizador y cronómetro.

## Estructura

```
index.html      Página única con las tres vistas
css/styles.css  Estilos
js/app.js       Aplicación con Three.js
favicon.svg     Icono
```

No requiere instalación ni compilación: abre `index.html` o sirve la carpeta con cualquier servidor estático.

## Funcionalidades

- Reloj analógico 3D con Three.js y paralaje de cámara.
- Temporizador con horas, minutos y segundos, presets, anillo de progreso y aviso sonoro.
- Cronómetro con pausa, vueltas y detección de la vuelta más rápida.
- Navbar flotante, menú móvil, navegación por hash y preferencia de movimiento reducido.
