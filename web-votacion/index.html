    Privacidad · La Papeleta

    La papeleta se guarda en tu navegador

    Esta web usa almacenamiento local para conservar los partidos, los votos y tu voto. No usa cookies, cuentas ni servidores. Al aceptar, la página se recargará para aplicar el guardado.

    Privacidad · sin guardado

    El escrutinio se reinicia al recargar

    Puedes inscribir partidos y votar durante esta visita, pero no se conservarán. Al recargar, la papeleta volverá a estar vacía. Puedes activar el guardado cuando quieras desde el botón «Privacidad».

    Privacidad · guardado activo

    El almacenamiento local está activo

    La papeleta conserva partidos, votos y tu voto en este navegador. Puedes retirar el permiso y borrar esos datos cuando quieras.

    Privacidad · borrar datos

    ¿Borrar los datos de la papeleta?

    Se eliminarán los partidos, los votos y la preferencia de consentimiento de este navegador. La página se recargará y el aviso volverá a aparecer.

    El navegador bloquea el almacenamiento local. No se pudo completar la operación.
